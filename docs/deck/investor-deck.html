01 · Executive Summary

The opportunity

Ethiopia's digital economy is growing fast, but freelancers are still paid informally — via bank transfer, cash, or offline brokers. Neither side has escrow, vetting, or a trusted rating system, and every price is quoted in a foreign currency that erodes the freelancer's take-home.

Problem

  • No trusted escrow — clients fear paying upfront; freelancers fear not being paid.
  • No vetting — anyone can claim expertise; quality is a gamble.
  • Off-platform payments in USD/foreign apps.
  • Mobile-first population, no marketplace built for Amharic.

Apex-Work solution

  • Escrowed orders with milestone releases and built-in dispute handling.
  • Identity-verified, reviewed freelancers with ratings & skills.
  • ETB-native: Chapa rails (Telebirr, CBE Birr, E-Birr).
  • Amharic + Tigrinya native UI, AI-powered search, voice messaging & calls.

Why now

  • Rapid smartphone adoption and mobile-money penetration.
  • Growing freelancer/remote-work culture among graduates.
  • Telebirr enables frictionless mass-market payments.
  • Established competitors serve Western/English markets only.

04 · Security & Trust

Built for a payments marketplace

Auth & identity

  • Phone-first with SMS OTP; optional OAuth.
  • Short-lived JWTs; refresh rotation.
  • Admin RBAC with per-capability roles (ADMIN/MODERATOR/SUPPORT/FINANCE).

Money safety

  • Escrow-held funds, milestone releases.
  • Dispute workflow + admin mediation.
  • Per-category, configurable platform fees.
  • Full order/financial audit trail.

Platform integrity

  • Moderation queue, suspend/verify tools.
  • Block + report + KPI threshold watcher.
  • 2FA-friendly admin console; sensitive ops audited (adminAudit).

Secrets are scoped to the server (service_role keys never reach the browser); uploads go through short-lived signed URLs with per-bucket type/size allowlists; server error telemetry via Sentry.

  • HTTP-level caching with SWR for public search/reads; Prisma cursor pagination (no OFFSET).
